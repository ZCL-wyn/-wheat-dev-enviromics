# Manuscript figures

Vector (PDF) and raster (PNG) versions of the six main figures.

| File | Panel content |
|---|---|
| `Figure1.png` / `.pdf` | Developmental enviromics framework and study overview |
| `Figure2.png` / `.pdf` | Phenology, reaction norms and genomic PCA |
| `Figure3.png` / `.pdf` | EWAS dot plot, covariate correlation heatmap, FW-LOOCV ranking, DTR–TKW relationship, LOOCV |
| `Figure4.png` / `.pdf` | GWAS for α and β, candidate loci and haplotype structure |
| `Figure5.png` / `.pdf` | Reaction-norm haplotypes and historical allele-frequency trajectories |
| `Figure6.png` / `.pdf` | Independent external validation |

PDF files are vector and are the preferred version for reproduction; the PNG files are provided
for convenient viewing on GitHub. Both were exported at 800 dpi from the scripts in this
repository. The script that assembles the combined figure is `15_combined_figure_v3.R`.
